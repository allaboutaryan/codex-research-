WHAT THIS IS / ISN’T

A testable workflow, not a promise

GitHub already helps people find starter issues. This pilot adds an explicit setup check and a clear route for getting help. A locally checked card is self-attested on this device, not endorsed by a repository maintainer. Issue availability and review time can change. Verify everything in the project itself before contributing.
